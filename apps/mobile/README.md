# @ledgeindex/mobile

Expo (React Native) client for LedgeIndex — talks to a hosted or self-hosted API via `@ledgeindex/client` (no on-device Mastra server).

## Develop

From the **ledgeindex** monorepo root:

```bash
npm run dev:mobile
# same as: npm run start -w @ledgeindex/mobile
```

Then press `a` for Android emulator, or scan the QR with a development build / Expo Go.
