# LedgeIndex

LedgeIndex turns documentation sites into something people and agents can ask: crawl, chunk, embed, retrieve, chat with citations.

## Start here

The main product path is the **[website widget](/docs/website-widget)** — embed Ask AI on your docs or product site with one script tag. Full steps: [Set up website widget](/guides/setup-widget).

For other setups (CLI, SDK, MCP, self-host), see **[Getting started](/guides)**.
