# Set up the website widget

Embed **Ask AI** on your site. Visitors chat on your domain; answers come from a LedgeIndex source you indexed.

Product overview: **[Website widget](/docs/website-widget)**.

## How it works

```text
Your site (https://docs.yoursite.com)     LedgeIndex cloud
┌─────────────────────────────┐         ┌──────────────────────────┐
│ <script data-website-id=…>  │  chat   │ api.ledgeindex.com       │
│ Ask AI launcher             │ ──────► │ allowlist check          │
│                             │         │ → your bound cloud source│
└─────────────────────────────┘         └──────────────────────────┘
         ▲
         │ you configure this origin in Website widget
         │ (https://docs.yoursite.com)
```

You choose which origins may call the widget. Copying your public `websiteId` onto a domain you did not allow returns `Origin not allowed`.

## Production (cloud)

For a public docs or product site:

1. **Index docs into Cloud** (not only on your laptop). [Index documentation](/guides/setup-docs) via the web app with **Cloud** hosting, or your cloud crawl flow.
2. Sign in → open **Website widget** (`/widget`).
3. Pick a **cloud source** (your cloud crawl or a public catalog source).
4. Under **Your website origins**, add each site one at a time (type origin → Add). Examples:

   - `https://docs.yoursite.com`
   - `https://www.yoursite.com`

   Use scheme + host (+ port if non-default). Path is ignored. `https://docs.yoursite.com/guides/foo` still counts as `https://docs.yoursite.com`.

   Add or remove origins later on the widget card and click **Save origins**.
5. Create the widget → **Copy snippet**.
6. Paste the snippet on your site (before `</body>`, Next `<Script>`, Webflow head, etc.).

The snippet uses `data-api-base-url="https://api.ledgeindex.com"` and the LedgeIndex CDN script. Local-only sources are not supported yet.

Visitors never sign in to LedgeIndex. Only allowlisted origins can chat.

## What "origin" means

| You type | Matches pages like |
|----------|-------------------|
| `https://docs.yoursite.com` | `https://docs.yoursite.com/…` |
| `https://yoursite.com` | `https://yoursite.com/…` (not `www` unless listed too) |
| `http://localhost:3000` | Dev preview only if you allowlist it on a cloud widget |

## Local-only sources

Not supported yet. The widget registry and chat API run on LedgeIndex cloud. Bind a **cloud-indexed** source or a **public** catalog source.

## Script attributes

```html
<script
  async
  src="https://storage.googleapis.com/ledgeindex-widget/ledgeindex-widget.bundle.js"
  data-website-id="wgt_YOUR_ID"
  data-api-base-url="https://api.ledgeindex.com"
  data-project-name="Ask AI"
  data-project-color="#6b5a3e"
></script>
```

| Attribute | Purpose |
|-----------|---------|
| `data-website-id` | Public id from Website widget |
| `data-api-base-url` | Cloud API (`https://api.ledgeindex.com`) |
| `data-project-name` | Header / launcher (default Ask AI) |
| `data-project-color` | Accent |
| `data-project-logo` | Optional logo URL |
| `data-example-questions` | Pipe-separated starters |

## Security

| Do | Don't |
|----|--------|
| Allowlist **your** site origins | Put `live_…` keys in frontend code |
| Use a **cloud** source for production | Point production traffic at a Local index |
| Treat `websiteId` as public | Assume an unlisted origin can chat |

**Embed abuse:** another site hosting your script is blocked. Browsers send the real `Origin`, which must match your allowlist.

**Scripted abuse:** callers can forge `Origin`. We rate-limit by IP and per widget (per minute and per day). That raises the cost of abuse; it is not a cryptographic guarantee. Disable a widget on the Website widget page if you see spikes.

API env vars: `WIDGET_RATE_IP_PER_MIN` (default 20), `WIDGET_RATE_SITE_PER_MIN` (60), `WIDGET_RATE_SITE_PER_DAY` (2000), `WIDGET_RATE_SITE_ORIGIN_PER_MIN` (40).

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `Origin not allowed` | Add the exact origin (scheme + host + port) on Website widget and save |
| Widget works on localhost, not prod | Prod origin missing from allowlist |
| Empty answers | Bound source not indexed, or Cloud widget pointed at wrong API |
| Cloud create fails | Widget routes must be live on `api.ledgeindex.com` (deployed docs profile) |
