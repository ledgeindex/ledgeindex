# Guides

How to run LedgeIndex from a clone of this repo. Package APIs live under [Docs](/docs) and [Reference](/reference).

| Guide | What you run |
|-------|----------------|
| [Set up web](/guides/setup-web) | API on `:3010` + Next.js UI on `:3004` + MCP at `/mcp` |
| [Set up desktop](/guides/setup-desktop) | Electron + local sidecar on `:3015` |

Clone [ledgeindex/ledgeindex](https://github.com/ledgeindex/ledgeindex). Install from that repo root. You do not need a sibling `ledgeindex-api` folder.
