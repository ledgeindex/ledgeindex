# Docs overview

LedgeIndex turns **documentation websites** into something people and agents can ask: crawl a docs URL, index it, and answer with **citations** to real pages.

The primary product surface for that is the **[website widget](/docs/website-widget)** — a floating Ask AI chat you embed with one script tag. No secret API keys in the browser; visitors stay on your domain.

Everything else (SDK, CLI, MCP, self-host) supports the same index — different doors into it.

## Start here: website widget

1. Index your docs ([guide](/guides/setup-docs)).
2. Create a widget under **Integrations** in the web app (bind a source, allowlist origins).
3. Paste the CDN script on your site.

→ **[Website widget](/docs/website-widget)** · step-by-step **[Set up website widget](/guides/setup-widget)**

```html
<script
  async
  src="https://storage.googleapis.com/ledgeindex-widget/ledgeindex-widget.bundle.js"
  data-website-id="wgt_YOUR_ID"
  data-api-base-url="https://api.ledgeindex.com"
  data-project-name="Ask AI"
></script>
```

## What else is available

**Indexing & chat**

- **Web crawl** — discover URLs, extract markdown, optional enrichment
- **Vector search + rerank** — FastEmbed + LibSQL locally; Postgres + Gemini for cloud-like stacks
- **Source chat (RAG)** — rewrite, retrieve, agent answer with citations (powers the widget and in-app chat)

## Ways to run without embedding a widget

| Surface | Package | Docs |
|---------|---------|------|
| Node scripts / CI | `@ledgeindex/sdk` | [SDK](/docs/sdk) |
| Terminal | `ledgeindex` | [CLI](/docs/cli) |

Both use FastEmbed + LibSQL by default under `~/.ledgeindex/data`. Ask and profile need a chat provider key.

## What ships in the monorepo

- **Packages** — `@ledgeindex/core`, `docs`, `profile`, `server`, `sdk`, `client`, `widget`, …
- **Web & desktop** — product UI, Electron, this docs site ([overview](/docs/apps))
- **Hosts** — API `:3010` (MCP `/mcp`), desktop sidecar `:3015`

Typical local ports: API **3010**, web **3004**, docs site **3005**.

## Pipeline (concept)

```text
discover → extract → enrich → chunk → embed → store → query
                                      │
                                      ├─ in-app chat / MCP / SDK ask
                                      └─ website widget (public embed)
```
