# Apps

LedgeIndex ships more than packages. These apps sit on top of the same API. Step-by-step env and run commands are in [Guides](/guides).

## Web (`@ledgeindex/web`)

Next.js UI on port **3004**. See [Set up web](/guides/setup-web).

Typical work:

- Connect documentation sources
- Run ingest / refresh
- Chat against an indexed source with citations
- Manage source sets

Point the UI at your API with `NEXT_PUBLIC_LEDGEINDEX_API_URL` (dev default `http://localhost:3010`).

On the hosted cloud product, accounts can be invite-only: after sign-in, access stays pending until an admin approves.

## Desktop (`@ledgeindex/desktop`)

Electron app. See [Set up desktop](/guides/setup-desktop).

It talks to a local sidecar (`hosts/desktop-server`) that runs `@ledgeindex/server` with docs + profile on **`:3015`**, so indexing can stay on the machine. Public / cloud sources need `NEXT_PUBLIC_LEDGEINDEX_REMOTE_API_URL`.

## Docs site (`@ledgeindex/docs-site`)

This site. Nextra on port **3005** (`npm run dev:docs` from the ledgeindex repo root).

## Mobile (`@ledgeindex/mobile`)

Expo app (`npm run start -w @ledgeindex/mobile`). Still early relative to web and desktop.

## Hosts

| Host | Role |
|------|------|
| `hosts/api` | OSS / hosted Fastify entry (`npm run dev:api`, `:3010`, MCP at `/mcp`) |
| `hosts/desktop-server` | Electron sidecar (`:3015`) |

Minimal open-source server: `LEDGEINDEX_PROFILES=docs,profile`.
