# Apps

LedgeIndex ships more than packages. These apps sit on top of the same API.

## Web (`@ledgeindex/web`)

Next.js UI on port **3004** (`npm run dev:ledgeindex`).

Typical work:

- Connect documentation sources
- Run ingest / refresh
- Chat against an indexed source with citations
- Manage source sets (including public/global sets for admins)

Point the UI at your API with `NEXT_PUBLIC_LEDGEINDEX_API_URL` when the API is not on the default origin.

On the hosted cloud product, accounts can be invite-only: after sign-in, access stays pending until an admin approves. Admins get a users panel for that.

## Desktop (`@ledgeindex/desktop`)

Electron app (`npm run dev:ledgeindex-desktop`). It talks to a local sidecar (`hosts/desktop-server`) that runs `@ledgeindex/server` with docs + profile, so indexing can stay on the machine.

## Docs site (`@ledgeindex/docs-site`)

This site. Nextra on port **3005** (`npm run dev:ledgeindex-docs` or VS Code task **Start LedgeIndex Docs**).

## Mobile (`@ledgeindex/mobile`)

Expo app (`npm run start -w @ledgeindex/mobile`). Still early relative to web and desktop.

## Hosts

| Host | Role |
|------|------|
| `ledgeindex-api` (workspace) | Hosted/dev API entry around `@ledgeindex/server` |
| `hosts/desktop-server` | Electron sidecar (docs + profile) |

Minimal open-source server: `LEDGEINDEX_PROFILES=docs,profile`.
