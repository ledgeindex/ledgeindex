# Profile API & lenses

## Package exports

| Export | Purpose |
|--------|---------|
| `profile` / `profileSite` | High-level site research profile |
| `runCompanyProfile` | Lower-level runner (name is historical) |
| `defaultProfileLenses` / `parseResearchLensList` | Lens helpers |
| `researchLensIds` / `getLensDefinition` | Introspect all 14 built-in lenses |
| `registerProfile` | Fastify routes for landscape runs |
| `LEDGEINDEX_PROFILE_VERSION` | Package version constant |

Legacy aliases still exported: `registerCompanyProfile`, `LEDGEINDEX_COMPANY_VERSION`.

## Lenses

Lenses are named research modes. Pass them as the second argument to `profileSite`.

- **`defaultProfileLenses()`** — all **14** built-in lenses
- **`parseResearchLensList("identity,pricing")`** — subset from CLI or env strings

See [Lenses reference](/reference/profile/lenses) for the full table (company, docs, package library / builder lenses).

## Manual harness

From the package:

```bash
npm run test:crawl-catalog-pick -w @ledgeindex/profile -- --mode profile
```

Useful for local debugging of catalog pick / lens synth. Not a CI unit test.
