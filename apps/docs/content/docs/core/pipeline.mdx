# Pipeline stages

Each stage is a core primitive. Compose only what you need. Guides live here; package import paths are under `@ledgeindex/core/*`.

## Crawl

Discover URLs and decide what to fetch.

Import under `@ledgeindex/core/crawl/*`.

## Extract

Turn HTML into usable text (`parsePage` / `fetchPageHtml`).

Import under `@ledgeindex/core/extract/*`.

## Enrich

Extract grounded code/setup/usage examples per page (skip if none).

Import under `@ledgeindex/core/enrich/*`.

## Chunk

Split content for embedding (`semantic-markdown` | `recursive`), then prepare/store for a source.

Import under `@ledgeindex/core/chunk/*`.

## Query

Common entry points:

- `kapaRetrieve` for markdown retrieval
- `queryExamples` with `chunkKind: "example"`

Import under `@ledgeindex/core/query/*` (and related retrieve helpers).

## Schemas

Zod configs for sources and metadata under `@ledgeindex/core/schemas/*`.
