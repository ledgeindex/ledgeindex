# @ledgeindex/profile

`@ledgeindex/profile` crawls a site once and runs **lenses** — named research modes that return structured JSON (positioning, pricing, capabilities, package guides, and others).

Profile output is not a search index. It fills fixed fields about what a site says. To index docs and ask questions over them, use [crawl + ask](/reference/sdk/crawl) instead. The two can be used together.

[Lenses](/reference/profile/lenses) · [Example output per lens](/reference/profile/lenses#example-output-per-lens)

## Install

```bash
npm install @ledgeindex/profile
```

## Primitive map

| Export | Purpose | Page |
|--------|---------|------|
| `profileSite` / `profile` | High-level research entry | [profileSite](/reference/profile/profile-site) |
| `runCompanyProfile` | Lower-level runner | [profileSite](/reference/profile/profile-site) |
| lenses helpers | `defaultProfileLenses`, `parseResearchLensList`, … | [Lenses](/reference/profile/lenses) |
| `registerProfile` | Fastify routes | used by [Server](/reference/server) |

## Typical compose

```ts
import { profileSite, defaultProfileLenses } from "@ledgeindex/profile";

const { profile } = await profileSite(
  "https://kapa.ai/",
  defaultProfileLenses(),
);

console.log(profile.identity);
console.log(profile.package_usage_examples);
```

Subset lenses for faster runs — see [Lenses](/reference/profile/lenses).
