# @ledgeindex/client

HTTP client for a **running** LedgeIndex API (web `:3010`, desktop sidecar `:3015`, or hosted).

**REST route map:** [HTTP API](/reference/api) — every `/api/*` path the web and desktop apps use.

## Install

```bash
npm install @ledgeindex/client
```

## API map

| Area | Exports | Page |
|------|---------|------|
| HTTP wrapper | `createLedgeIndexClient`, `resolveApiBaseUrl` | [Auth & URLs](/reference/client/auth) |
| Sources | `listSources`, `createSource`, `getSource`, `updateSource`, `deleteSource`, … | [Sources & ingest](/reference/client/sources) |
| Crawl orchestrator | `runWebCrawl`, `defaultWebCrawlConfig` | [runWebCrawl](/reference/client/crawl) |
| Ask | `askSource` | [Sources & ingest](/reference/client/sources) |
| Preflight / crawl helpers | `preflightSite`, `proposeCrawlFilterRemovals`, `getCrawlProgress`, … | [Sources & ingest](/reference/client/sources) |

## Quick start

```ts
import {
  createLedgeIndexClient,
  resolveApiBaseUrl,
  listSources,
  askSource,
} from "@ledgeindex/client";

// Point at your API
createLedgeIndexClient({
  apiBaseUrl: resolveApiBaseUrl() ?? "http://127.0.0.1:3010",
});

const sources = await listSources("personal");
const answer = await askSource(sources[0]!.id, "How do I install?");
console.log(answer.answer);
```

## vs `@ledgeindex/sdk`

| | Client | SDK |
|---|--------|-----|
| Transport | HTTP to Fastify API | In-process (`@ledgeindex/docs`) |
| Server | Required | Not required |
| Auth | Bearer / API key | Keys in env / options |
| Same crawl flow | `runWebCrawl` (HTTP) | `li.crawl` (in-process) |

Use **Client** when the UI or a remote API is already running. Use **SDK** for scripts and workers without starting a server.
