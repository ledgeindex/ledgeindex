## Install versions

Published packages are versioned together (currently **0.1.7**). Prefer matching versions across `@ledgeindex/*` in an app.

## Runtime check

```http
GET /health/packages
```

Returns `@ledgeindex/core` / `@ledgeindex/server` versions and the active profile list.
