# Reference

Package APIs for integrating LedgeIndex. **New here?** Start with [Guides → Getting started](/guides) (what to run and when). **How to run** web, CLI, Docker, and MCP is there; this section is API surfaces.

## Which package?

| You want to… | Package | Needs a server? |
|--------------|---------|-----------------|
| Crawl + ask + profile from a Node script or worker | [`@ledgeindex/sdk`](/reference/sdk) | No — in-process |
| Call a running API (`:3010` web, `:3015` desktop) | [`@ledgeindex/client`](/reference/client) | Yes |
| Terminal crawl, ask, profile | `ledgeindex` (CLI) | No — uses SDK |
| MCP in Cursor / Claude Desktop | Running API `/mcp` | Yes — see [Set up MCP](/guides/setup-mcp) |
| Host your own Fastify API | [`@ledgeindex/server`](/reference/server) | You run it |
| Low-level crawl / chunk / embed / query only | [`@ledgeindex/core`](/reference/core) | No — compose yourself |
| **Git repo index** — AST chunking, clone, walk | [`@ledgeindex/repo`](/reference/repo) | No — via SDK init + `indexRepoCheckout` |
| **Sources, indexing, chat, MCP** (what the web app does) | [`@ledgeindex/docs`](/reference/docs-runtime) | Via server, SDK, or CLI |
| Site research lenses (pricing, identity, …) | [`@ledgeindex/profile`](/reference/profile) or SDK [`profile`](/reference/sdk/profile) | In-process via SDK/CLI; HTTP via server |

**Rule of thumb:** start with **SDK** (no server) or **Client** (server already running). Reach for **Core** only when you need custom pipelines.

## HTTP API (web & desktop)

The web UI and desktop app talk to Fastify on **`:3010`** (web) or **`:3015`** (desktop). Route reference:

| Area | Page |
|------|------|
| Overview, base URLs, auth | [HTTP API](/reference/api) |
| Sources, ingest, ask, profile, … | [Route map](/reference/api#route-map) |

No OpenAPI spec yet — use [HTTP API](/reference/api) + [`@ledgeindex/client`](/reference/client) types.

## Install versions

Published `@ledgeindex/*` packages are versioned together. Prefer matching versions in one app.

## Runtime check

When an API is running:

```http
GET /health/packages
```

Returns installed `@ledgeindex/*` versions and active profiles.
