# @ledgeindex/sdk

High-level in-process API — crawl, index, ask, and profile **without** a running HTTP server. Same stack as the CLI (`ledgeindex`).

## Install

```bash
npm install @ledgeindex/sdk
```

## Quick start

```ts
import { createLedgeIndex } from "@ledgeindex/sdk";

const li = await createLedgeIndex({
  keys: { google: process.env.GOOGLE_GENERATIVE_AI_API_KEY },
});

const { sourceId } = await li.crawl({
  url: "https://docs.example.com",
  maxPages: 20,
});

const { answer } = await li.ask(sourceId, "How do I install?");
console.log(answer);
```

## vs `@ledgeindex/client`

| | SDK | Client |
|---|-----|--------|
| Server | Not required | API on `:3010` / `:3015` |
| Data dir | `~/.ledgeindex/data` (default) | Server’s data store |
| Auth | Keys in options / env | Bearer token or API key |
| Best for | Scripts, CI, workers | Web UI, remote API, desktop sidecar |
